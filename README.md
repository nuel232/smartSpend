# SmartSpend - Digital Wallet App

SmartSpend is a modern digital wallet application built with React Native and Expo, designed to help users manage their finances in Nigerian Naira (₦) with ease and security.

## Features

- 🔐 Secure Authentication System
- 💰 Digital Wallet Management in Naira (₦)
- 💳 Transaction Tracking & History
- 📊 Balance Overview with Real-time Updates
- 🔄 Recent Transactions Dashboard
- 📱 Smooth Animations & Modern UI
- ⚡ Quick Navigation Between Screens

## Tech Stack

- React Native
- Expo Router for Navigation
- TypeScript for Type Safety
- Context API for State Management
- React Native Animations for Smooth UX

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Expo CLI
- iOS Simulator or Android Emulator

### Installation

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the app: `npx expo start`
